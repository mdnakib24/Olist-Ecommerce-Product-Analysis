Olist E-Commerce Product Analysis

Project Overview

This project analyzes Olist e-commerce data to understand sales performance, product category performance, and customer location trends using SQL and Power BI.

Tools Used

MySQL – Data analysis using SQL queries

Microsoft Excel – Data inspection and handling

Power BI – Interactive dashboard creation

Dashboard Features

Total Sales KPI

Best Performing Product Category

Product Category Analysis

Top 10 Categories by Sales

Sales Distribution by Category

City and State Filters

Key Insights

Identified the best-performing product category based on sales.

Compared sales performance across different product categories.

Analyzed top 10 categories by sales.

Created an interactive dashboard to explore sales data.

Project Objective

The objective of this project is to analyze e-commerce sales data and build an interactive dashboard to help understand product performance and sales trends.
